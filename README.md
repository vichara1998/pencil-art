A polished, browser-based editor for turning ordinary photos into expressive pencil-style artwork. Built with React, TypeScript, and Vite, Pencil Art gives you a creative workspace for image transformation, grid-based drawing, and export-ready results.

## 🌈 Why Pencil Art?

Pencil Art combines photo editing and hand-drawn aesthetics into a single powerful workflow. Upload an image, fine-tune the artistic settings, and generate a stylized result that feels handcrafted while remaining precise and editable.

### Highlights

- Drag-and-drop image upload support
- Pencil-grid and color-grid art modes
- Adjustable brightness, contrast, and paper texture
- Fine control over pencil sensitivity, thickness, darkness, and color
- Reusable canvas styling with live visual feedback
- Export-ready artwork for sharing or printing
- Responsive interface for both desktop and smaller screens

## ✨ Features

### Artistic controls

- Grid-based rendering with configurable cell density
- Color palette reduction for stylized output
- Number overlays for guided drawing workflows
- Pencil tone simulation with paper brightness adjustments
- Image enhancement controls for stronger contrast and clearer tonal ranges

### Workflow

- Upload a PNG, JPG, WEBP, BMP, or GIF image
- Apply artistic modes and styling adjustments
- Refine the result directly on the canvas
- Export the final design in a clean, presentation-ready form

## 🚀 Getting started

### Prerequisites

- Node.js 18+
- npm or yarn

### Install dependencies

```bash
npm install
```

### Run the app locally

```bash
npm run dev
```

Then open the local Vite URL shown in the terminal, typically:

```bash
http://localhost:5173
```

### Production build

```bash
npm run build
```
